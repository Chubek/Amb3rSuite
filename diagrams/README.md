Rendered SVGs are vector diagrams. Graphviz `.dot` files are editable source; regenerate with `dot -Tsvg name.dot -o name.svg`. RC circuit SVG is directly editable. Diagrams describe proposed architecture, not implemented application features.

`rc-circuit.svg` shows the actual ideal reference topology; `rc-waveform.svg` plots the analytical continuous and backward-Euler formulas, not simulated or measured data.
