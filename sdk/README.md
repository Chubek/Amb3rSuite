# Reference C SDK

This small C11 example demonstrates the proposed ABI's read-only trusted linked command profile. The reference host supports a single registered command and one staged diagnostic, sticky failures, exact ABI prefix, explicit capability grants and stale revision rejection. It is not a general registry, dynamic loader, complete transaction service, sandbox or production ABI. No untrusted code may run in it. Production obligations are in chapter 10. To author an extension, copy the pattern from `examples/plugin.c`, use length-aware spans, declare required capabilities, avoid retaining call-scoped state, and check every status. Full C SDK facets are future work. Build: `cmake -S sdk -B /tmp/amb3r-sdk; cmake --build /tmp/amb3r-sdk; ctest --test-dir /tmp/amb3r-sdk --output-on-failure` from workbook root.
